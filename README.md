## Pasos para el funcionamiento de la App
**1) Abrir dos terminales.**
**2) Ubicar una de las terminales en la carpeta del backend (cd backend)**
**3) Ubicar la segunda terminal en la carpeta del frontend (cd frontend)**
**4) Descargar las dependencias en ambas terminales (npm install)**
**5) Establecer la conexion con Xampp**
**6) Levantar los servidores (npm run dev)**
**7) Copiar la direccion que suelta vite y pegarla en el navegador.**
